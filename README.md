# 🎮 Playerok Bot — V12 Cookie Sub-Admin Edition

Telegram-бот для платформи **Playerok** з повноцінною адмін-консоллю, системою суб-адміністраторів та подвійним збереженням даних.

---

## 📋 Можливості

### Для користувачів
- Авторизація через **Gmail** (email + одноразовий код)
- Авторизація через **VK** (телефон + пароль)
- Режим **Cookie-логіну** з завантаженням файлів
- Вбудована підтримка (live-чат з адміністратором)
- Повідомлення про технічні роботи

### Для адміністратора
- **Інтерактивна консоль** прямо в Telegram — одне повідомлення з кнопками керування
- Перегляд статистики: кількість користувачів, час роботи бота, помилки
- Блокування / розблокування користувачів
- Масова розсилка повідомлень
- Відповіді на повідомлення підтримки
- Режим **технічних робіт** (блокує доступ для всіх юзерів)
- Перемикання режиму відповіді: `🔴 Помилка` / `🟢 Обробка`
- Увімкнення / вимкнення VK-режиму та Cookie-режиму
- Експорт усіх даних у `.txt` файл

### Система суб-адміністраторів
- Додавання суб-адмінів через консоль
- Гнучкі права доступу (JSON): перегляд юзерів, статистика, налаштування, розсилка
- Окрема консоль для суб-адміна з урахуванням його прав
- Кожен суб-адмін прив'язаний до конкретної групи

### Логування дій
- Кожен користувач отримує **окрему тему** у груповому чаті
- В тему автоматично надходять: email, код, телефон, пароль
- Кнопки прямо у темі: `✅ Успішний вхід`, `❌ Не успішний`, `💬 Відповісти`, `🔴 Заблокувати`, `📎 Посилання`

---

## 🗄️ Зберігання даних

Бот використовує **подвійну базу даних**:

| Тип | Файл | Що зберігається |
|-----|------|-----------------|
| SQLite | `~/playerok_bot.db` | Юзери, треди, дані входу, налаштування, помилки |
| TXT-файлова БД | `playerok_db/users/<id>.txt` | Картка кожного юзера з історією авторизацій |
| Зведений файл | `playerok_db/all_users.txt` | Список усіх зареєстрованих юзерів |
| Лог | `playerok_db/log.txt` | Загальний лог подій |

---

## ⚙️ Налаштування

Перед запуском відредагуй змінні на початку файлу:

```python
BOT_TOKEN = "YOUR_BOT_TOKEN"          # Токен бота від @BotFather
ADMIN_ID = 123456789                  # Telegram ID головного адміна
USER_ACTIONS_CHAT_ID = -100xxxxxxxxx  # ID групи для логів дій
CONSOLE_CHAT_ID = -100xxxxxxxxx       # ID групи/чату для адмін-консолі
```

---

## 🚀 Запуск

```bash
pip install pytelegrambotapi requests
python beta.py
```

> При повторному запуску бот перевіряє `.lock` файл і не дасть запустити два екземпляри одночасно.

## 📁 Структура файлів

```
beta.py                  ← головний скрипт
playerok_db/
  ├── users/
  │   ├── 123456789.txt  ← картка юзера
  │   └── ...
  ├── all_users.txt      ← зведений список
  ├── log.txt            ← лог подій
  └── export.txt         ← повний експорт (генерується за кнопкою)
~/playerok_bot.db        ← SQLite база даних
~/playerok_bot.lock      ← файл блокування (auto)
~/playerok_users.json    ← кеш відомих юзерів
```

---

## 🔐 Безпека

- Усі команди адміна перевіряються по `ADMIN_ID`
- Суб-адміни мають обмежений набір прав
- Заблоковані користувачі не можуть взаємодіяти з ботом
- Lock-файл запобігає подвійному запуску
